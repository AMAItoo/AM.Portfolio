> مساعد محادثة ذكي ثنائي اللغة (عربي افتراضي/إنجليزي) لموقع العمل الحر،
> يرد فقط من معرفة البورتفوليو، يقدّم الخدمات، ويحوّل العميل الجاد إلى واتساب.

## 1) الهدف ومعايير النجاح

- زائر يسأل بأي لغة → رد بلغته (العربية الافتراضية)، من معلومات الموقع فقط.
- سيناريو مضمون: يسأل الاسم → يعرض 7 خدمات بأزرار → يشرح المختارة
  باختصار (مع رابط الديمو إن وجد) → يدعوه لمحادثة واتساب.
- تحويل واتساب: `wa.me/201553851517` بنص معبأ (اسم العميل + الخدمة).
- مجاني 100% مفتوح المصدر، بلا انقطاع (لا نوم للخادم)، بلا كشف مفاتيح.

## 2) المعمارية

```
المتصفح (موقع GitHub Pages)                HF Space (FastAPI, مجاني CPU)
┌──────────────────────────┐   POST /chat  ┌───────────────────────────────┐
│ chatbot.js + chatbot.css │ ────────────▶ │ آلة حالات (الاسم→خدمة→واتساب) │
│ زر عائم RTL/LTR + فقاعات │ ◀──────────── │ RAG: ChromaDB + MiniLM-L12    │
│ أزرار سريعة + زر واتساب  │   JSON رد     │ LLM: Groq llama-3.3-70b       │
└──────────────────────────┘               │ (احتياط: Gemini Flash)        │
                                           │ المعرفة: knowledge/*.md       │
                                           └───────────────────────────────┘
```

- **الاستضافة**: Hugging Face Space (FastAPI، SDK=Docker) — يعمل دائمًا مجانًا؛
  إعادة بناء الفهرس تلقائيًا عند كل إقلاع (ثوانٍ).
- **LLM**: Groq (`llama-3.3-70b-versatile`) أساسي، Gemini 2.0 Flash احتياط تلقائي
  عند 429/نفاد الحصة. المفاتيح أسرار في الـ Space (لا شيء في الكود).
- **RAG**: تقسيم العناوين/الفقرات → `paraphrase-multilingual-MiniLM-L12-v2`
  → ChromaDB PersistentClient (قرص الـ Space) → top-4 قطع.
- **حارس الأمانة**: الرد يُبنى فقط من السياق المسترجع + حالة المحادثة؛
  خارج النطاق → رد مهذب يوجّه للواتساب.

## 3) المعرفة (knowledge/)

Markdown ثنائي اللغة (كل سطر مفتاح `ar:` / `en:` أو ملفان متوازيان):
`about.md` (خبرات + نبذة) · `services.md` (7 خدمات بالتفصيل) ·
`projects.md` (6 مشاريع + روابط الديمو) · `faq.md` (أسئلة شائعة: الأسعار/المدة/التواصل).
روابط الديمو كلها داخلية على نفس الدومين (تُعاد كروابط قابلة للنقر).

## 4) آلة الحالات (السيناريو البيعي)

```
greet → ask_name → ask_service (7 أزرار سريعة) → service_detail (RAG)
      → offer_demo (إن وجد) → offer_whatsapp → handoff (رابط معبأ)
```
- الاسم يُلتقط من رسالة نصية عادية، يُخزن في جلسة الذاكرة فقط (لا تخزين دائم).
- في أي حالة: سؤال حر → LLM+RAG ثم العودة للحالة نفسها.
- التحويل: `https://wa.me/201553851517?text=<اسم+خدمة+تحية>` (نفس رقم الموقع).
- اللغة: الرد بلغة آخر رسالة من الزائر؛ الواجهة تتبع لغة الصفحة (RTL عربي).
